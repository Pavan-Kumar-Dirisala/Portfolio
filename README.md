## 🚀 Run Locally

1. Clone the repository:
   ```
   git clone https://github.com/pavan-kumar-dirisala/Portfolio.git
   ```
2. Navigate to the project directory:
   ```
   cd Portfolio
   ```
3. Open the project in Visual Studio Code.
4. Launch `index.html` using the **Live Server** extension.

Alternatively, open `index.html` directly in your browser.

## 🌍 Deployment

This portfolio is hosted using **GitHub Pages**.

To deploy your own changes:

1. Push the updated files to the GitHub repository.
2. Open the repository's **Settings**.
3. Navigate to **Pages**.
4. Select the deployment branch and root folder.
5. Save the settings and wait for GitHub Pages to publish the website.
